# Bileto - Event Tickets for WooCommerce

Sells event tickets as ordinary WooCommerce products. WooCommerce owns the cart, payments, coupons and taxes; invoices come from your invoicing plugin. Bileto adds tickets, attendees, QR codes, ticket transfer and check-in.

Status: skeleton (stage 0), no features yet.

## Requirements

- PHP >= 8.1
- WordPress >= 6.5
- WooCommerce >= 8.0

## Development

```bash
composer install
composer test
composer cs
composer analyse
npx wp-env start
```
